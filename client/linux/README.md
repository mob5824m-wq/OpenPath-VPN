# Legacy Linux Electron GUI

This directory is an older Electron-based GUI and session implementation, retained for reference and regression tests. **It is not the released Linux application.** The Linux, Windows and macOS releases are built from the non-web [Qt Widgets client](../native/README.md).

The experimental `tun-linux.ts` and CLI scaffolding are not the WireGuard implementation and should not be relied on for device protection. See the [root README](../../README.md#device-wide-wireguard-vpn) for the native client's prerequisites, profile requirements and safety limitations.
