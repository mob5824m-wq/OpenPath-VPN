# OpenPath Brand Assets

- `logo.png` — Main shield + path + circuit (primary, 1024×1024, transparent)
- `icon-512.png` — App icon (512×512, for stores, tray)
- `branding/logo-main.png` — Full lockup (copy of logo.png)
- Derived: `icon-256.png`, `icon-128.png`, `icon-64.png`, `favicon.ico`, `tray.png` generated at build.

Palette:
- Deep Navy `#0b132b` (shield rim)
- Electric Cyan `#0ea5e9`
- Violet `#6366f1` (gradient right rim)
- Light `#f8fafc` (background)
- Green `#0bb07b` for connected status (like Proton)
- Amber `#f59e0b` for connecting

Font: Inter (UI), JetBrains Mono (stats)

Usage: Keep clear space = ¼ shield height. Never stretch. Use white or navy background.
